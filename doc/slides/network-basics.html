What a network packet actually is — before any of the FPGA part matters.

You want to send something.

A wire can only carry voltage changes. Everything below is the machinery that turns that into "this message, for that machine, for that program".

But the wire is shared.

machine A
you
machine C
machine D
machine E

Everyone's traffic goes past everyone. So every message has to carry who it is for — and that is what a header is.

A packet is envelopes inside envelopes.

Ethernet — for the machine next door
IP — for the machine across the world
UDP — for the program on it
your data

Each envelope answers one question.

Ethernet Which machine on this cable? MAC address · 6 bytes
IPv4 Which machine anywhere? IP address · 4 bytes
UDP Which program on that machine? port · 2 bytes
Payload The thing you actually wanted to send. the rest

Ethernet address — burned into the network chip

001122 334455

A MAC address. Fixed at the factory, unique in the world — but only meaningful to machines on the same local wire. It cannot get you across the internet.

IP address — assigned, and routable

23919202

An IP address. Four bytes, handed out rather than burned in. This one can cross the planet, because routers know how to forward it.

IP is the destination. MAC is the next step. That is the whole difference, and it is why there are two address layers instead of one.

One machine runs many programs. The IP address gets the packet to the machine; the port gets it to the right program.

Two ways to send it.

TCP
1 · are you there?
2 · yes, I am there
3 · here is packet #1
4 · got #1
5 · #2 never arrived → send it again
UDP
1 · here is a packet

No setup. No acknowledgement. No retry. No ordering. If it is lost, it is lost.

TCP guarantees delivery. It buys that with round trips.

why market data is UDP

By the time TCP could recover a lost packet, the market has moved. Speed is worth more than completeness.

The exchange sends each update once, to a group address like 239.192.0.2. The network duplicates it. Everyone gets the same bytes at the same moment — which is also what makes it fair.

Was it damaged in transit?

add all ten  →  2​FFFD  ·  carry the 2 back to the bottom
= FFFF  →  intact

The amber word is chosen to make the total come out all-ones. One flipped bit anywhere and it no longer does — so the packet gets thrown away instead of believed.
