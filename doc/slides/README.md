# Slides

Two decks, meant to be read in order. Both are standalone HTML — open them in a
browser, navigate with the arrow keys or by clicking.

| | Deck | Assumes |
| --- | --- | --- |
| 1 | [`network-basics.html`](network-basics.html) — **Bytes on a Wire** | nothing. What a packet is, why there are two address layers, UDP vs TCP, multicast, checksums |
| 2 | [`netparse-overview.html`](netparse-overview.html) — **The 67-Nanosecond Budget** | deck 1. Why parsing 42 bytes at line rate is hard, and what this design does about it |

Read deck 1 first if "MAC address", "multicast" or "port" are not already
familiar; deck 2 opens assuming all three.
